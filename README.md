# Wordle CLI
 
Консольная реализация игры Wordle на русском языке. Проект написан на чистом Python (стандартная библиотека) без использования сторонних зависимостей.
 
## Описание
 
Игра загадывает слово из 5 букв. Игроку дается 6 попыток, чтобы его угадать. После каждой попытки буквы подсвечиваются:
- Зеленым: буква находится на своем месте.
- Желтым: буква есть в слове, но стоит в другом месте.
- Серым: буквы нет в загаданном слове.
 
В реализации корректно обрабатываются повторяющиеся буквы (аналогично оригинальной игре).
 
## Возможности
 
- Цветной вывод в терминале с использованием ANSI-кодов.
- Сохранение статистики: количество побед, винрейт, текущая и максимальная серии побед.
- Режим "Слово дня" (детерминированный выбор слова на основе текущей даты).
- Генерация результата в виде цветных блоков для шаринга.
- Отсутствие внешних зависимостей (используется только стандартная библиотека Python).
 
## Требования
 
- Python 3.9 или выше.
- Терминал с поддержкой ANSI-цветов (Windows Terminal, PowerShell, Linux, macOS).
 
## Установка и запуск
 
1. Склонируйте репозиторий:
   git clone https://github.com/ivancheke228/wordle.git
   cd wordle
 
2. Запустите игру:
   python wordle.py
 
## Использование
 
По умолчанию игра загадывает случайное слово из словаря:
   python wordle.py
 
Доступные аргументы командной строки:
   python wordle.py --daily      # Загадать слово дня (зависит от текущей даты)
   python wordle.py --stats      # Показать статистику и выйти
   python wordle.py --word время # Задать конкретное слово (для тестирования)
 
Для выхода из игры во время процесса введите "выход", "exit" или "q".
 

> 
 
## Структура проекта
 
- wordle.py - основной исходный код игры.
- words.txt - словарь из 5-буквенных слов. Каждое слово на новой строке.
- wordle_stats.json - файл со статистикой (создается автоматически при первой игре).
 
## Добавление слов
 
Для изменения словаря отредактируйте файл words.txt. Убедитесь, что каждое слово содержит ровно 5 русских букв (буква "ё" также допускается).
